# AI-Driven Employee Attrition Prediction and Workforce Analytics

## BAD702 – Statistical Machine Learning for Data Science

### Project Overview

This project analyzes employee attrition using statistical analysis and machine learning techniques. The project follows a complete data science workflow from data cleaning and exploratory data analysis to statistical testing, regression, discriminant analysis, machine learning and interactive prediction.

The project uses the IBM HR Analytics Employee Attrition & Performance dataset.

## Objectives

- Perform data cleaning and preprocessing.
- Conduct Exploratory Data Analysis (EDA).
- Analyze sampling distributions and confidence intervals.
- Perform hypothesis testing and A/B testing.
- Apply simple and multiple linear regression.
- Apply Linear Discriminant Analysis (LDA).
- Build Logistic Regression and Random Forest models.
- Evaluate models using Accuracy, Precision, Recall and F1-score.
- Build an interactive Streamlit dashboard for employee attrition prediction.

## Dataset

- Records: 1,470
- Attributes: 35
- Target: `Attrition`
- Classes: `Yes` and `No`
